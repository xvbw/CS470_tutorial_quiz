0. Live Setup (Local Environment)

Let's build your professional deep learning workspace.

Why are we doing this? Before writing a single line of AI code, we must construct a safe, isolated room in your computer. This prevents PyTorch from breaking your other Python projects, and allows us to hook up your GPU.

Step 1: Why Virtual Environments?

  • Python projects require specific versions of libraries.
  • If Project A needs PyTorch 1.0 and Project B needs PyTorch 2.0, installing them globally causes Dependency Hell.
  • Solution: Conda creates "isolated boxes" for each project.
The Conda Advantage 🐍 Conda isn't just for Python packages; it can install complex C++ libraries (like Nvidia's CUDA toolkit) which PyTorch desperately needs to talk to your GPU.
Before Step 2: Install a Conda distribution for your operating system, then open a new terminal and verify it with conda --version.

Windows: Download Miniconda .exe → install to the default location.

2. The Quickstart

A 10,000-foot view of an AI pipeline.

The Big Picture 🌍 Before we look at the microscopic details, let's fly over a complete deep learning workflow: Data -> Batches -> Model -> Training -> Evaluation.

Step 1: Get the Data

from torchvision import datasets
from torchvision.transforms import ToTensor

# Download Fashion Images
train_data = datasets.FashionMNIST(
    root="data", train=True, download=True, transform=ToTensor()
)
ToTensor() is mandatory 🖼️ Images are made of pixels ranging from 0-255. Neural networks hate large numbers. `ToTensor` instantly squashes all pixels into decimals between 0.0 and 1.0.
Check: Keep the requested data and labels intact; check batch and label shapes.

Step 2: DataLoader

from torch.utils.data import DataLoader

# Batch data into chunks of 64
train_loader = DataLoader(train_data, batch_size=64)

for X, y in train_loader:
    print(X.shape) # Images
    print(y.shape) # Labels
    break
torch.Size([64, 1, 28, 28]) torch.Size([64])
Why Batch? 📦 You cannot shove 60,000 images into a GPU at once; the memory will explode. The DataLoader acts like a conveyor belt, feeding the GPU exactly 64 images at a time.

Step 3: The Model

from torch import nn

class NeuralNetwork(nn.Module):
    def __init__(self):
        super().__init__()
        self.flatten = nn.Flatten()
        self.stack = nn.Sequential(
            nn.Linear(28*28, 512), nn.ReLU(),
            nn.Linear(512, 10)
        )

    def forward(self, x):
        return self.stack(self.flatten(x))
The Architecture 🏗️ `nn.Module` is the base template. `__init__` is where you buy your Lego bricks (layers). `forward()` is where you click them together to define how the data flows.

3. Tensors

The microscopic building blocks of AI.

What is a Tensor? It is a multi-dimensional matrix. It looks and acts exactly like a NumPy array, but with two superpowers: it can live on a GPU, and it remembers its own calculus history.

Tensor DNA (Attributes)

t = torch.rand(3, 4)

print(t.shape)   # Dimensions
print(t.dtype)   # Data type (float32, int64)
print(t.device)  # CPU or GPU?
torch.Size([3, 4]) torch.float32 cpu
Bug Alert 🐛 90% of your deep learning errors will be because Tensor A's `shape` doesn't match Tensor B, or Tensor A is on the CPU while Tensor B is on the GPU.
Check: Preserve image proportions. Resize then center-crop or pad; do not stretch a photo to a square. Preprocessing is required.

5. Transforms

Massaging raw data into clean mathematical arrays.

Why do we need this? 🧼 Images are different sizes, pixels are huge numbers, and labels are text words. Neural networks only understand standardized, small decimals. Transforms fix this.

ToTensor()

from torchvision.transforms import ToTensor

# Transforms PIL images to FloatTensors
transform = ToTensor()
The Hidden Math ➗ `ToTensor` doesn't just change the format. It takes a pixel with a color value of `255` and divides it by 255. Now it is `1.0`. This prevents "exploding gradients" during matrix math.
Check: For pretrained weights, use their matching preprocessing: resize/crop, scale, and normalize.

7. Autograd

The engine that computes complex derivatives instantly.

The Core of AI 🧠 Autograd is why Deep Learning exists today. It calculates the exact derivative of millions of parameters in milliseconds, telling the model exactly how to correct its mistakes.

Turning Autograd OFF

Tracking math takes massive memory. Turn it off when testing!

# Method 1: Context Manager (Best for inference)
with torch.no_grad():
    y = w * x
print(y.requires_grad)

# Method 2: Detach (For a single tensor)
z = (w * x).detach()
print(z.requires_grad)
False False
Save your RAM 💾 If you run testing data without `torch.no_grad()`, PyTorch will needlessly build massive derivative graphs, eventually crashing your GPU memory.
Check: For inference, use both model.eval() and torch.no_grad(); they do different jobs.

9. Save & Load

Don't lose your 40-hour training run when the PC reboots.

Preserving Knowledge 🧠 A trained model is just a giant list of perfectly tuned decimals. We need to save those decimals to the hard drive.

The Evaluation Trap ☠️

# You MUST call this before testing/inference!
new_model.eval()
Avoid Wild Predictions 🎲 Layers like `Dropout` randomly turn off neurons to prevent overfitting. `eval()` freezes the network so it behaves consistently and accurately for users.
Check: After loading weights for inference, call eval() before predicting.
